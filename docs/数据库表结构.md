## t_alert_record

告警记录表。该表为 TimescaleDB 超表，以 `create_time` 作为时间分区字段。

### 字段

| 序号 | 字段 | 类型 | 可空 | 默认值 | 说明 |
| ---: | --- | --- | :---: | --- | --- |
| 1 | `id` | `character varying(32)` | 否 | - | 告警记录主键，32位UUID |
| 2 | `sensor_no` | `character varying(50)` | 否 | - | 传感器编号（关联 `t_sensor.sensor_no`） |
| 3 | `threshold_id` | `character varying(32)` | 是 | - | 触发告警的阈值规则ID（关联 `t_alert_threshold.id`）；非阈值类告警可为空 |
| 4 | `trigger_val` | `numeric` | 是 | - | 告警触发时的实际监测值 |
| 5 | `create_time` | `timestamp(6) without time zone` | 否 | `CURRENT_TIMESTAMP` | 首次告警时间，默认当前时间 |
| 6 | `alert_status` | `smallint` | 否 | `0` | 告警状态：0未处理，1已处理，默认0 |
| 7 | `channel` | `character varying(50)` | 否 | `''::character varying` | 监测通道，空字符串表示默认通道 |
| 8 | `seq` | `bigint` | 否 | `nextval('t_alert_record_seq_seq'::regclass)` | 告警增量推送序列号，用于SSE推送和游标轮询，默认自增 |
| 9 | `alert_type` | `character varying(30)` | 否 | `'阈值超限'::character varying` | 告警类型：阈值超限、传感器离线、采集仪离线、传感器死值、超物理量程，默认阈值超限 |
| 10 | `alert_level` | `smallint` | 否 | `1` | 告警等级：阈值超限支持1/2/3级；其余告警类型固定为1级，默认1 |
| 11 | `handle_by` | `character varying(64)` | 是 | - | 处理人 |
| 12 | `handle_time` | `timestamp(6) without time zone` | 是 | - | 处理时间 |
| 13 | `end_time` | `timestamp(6) without time zone` | 是 | - | 告警结束时间 |
| 14 | `alert_category` | `smallint` | 否 | `0` | 预警分类：0=数据预警，1=设备预警，默认0 |
| 15 | `handle_opinion` | `text` | 是 | - | 处理意见 |
| 16 | `handle_phone` | `character varying(32)` | 是 | - | 处理人电话 |
| 17 | `rule_snapshot` | `jsonb` | 否 | `'{}'::jsonb` | 预警首次创建时保存的规则内容；活动预警后续更新不再修改，默认空JSON对象 |
| 18 | `alert_function` | `integer` | 是 | - | 预警功能分类：1=结构，2=环境 |

### 约束与索引

当前表没有显式主键、唯一、外键或检查约束。

| 索引 | 定义 |
| --- | --- |
| `idx_alert_record_id` | `CREATE INDEX idx_alert_record_id ON public.t_alert_record USING btree (id)` |
| `idx_alert_record_query` | `CREATE INDEX idx_alert_record_query ON public.t_alert_record USING btree (sensor_no, channel, create_time DESC)` |
| `idx_alert_record_seq` | `CREATE INDEX idx_alert_record_seq ON public.t_alert_record USING btree (seq)` |
| `idx_alert_record_status` | `CREATE INDEX idx_alert_record_status ON public.t_alert_record USING btree (alert_status, alert_level, create_time DESC)` |
| `t_alert_record_create_time_idx` | `CREATE INDEX t_alert_record_create_time_idx ON public.t_alert_record USING btree (create_time DESC)` |

### TimescaleDB 配置

| 配置项 | 值 |
| --- | --- |
| 超表时间字段 | `create_time` |
| 时间分块间隔 | `7 days` |
| 压缩分段字段 | `sensor_no`, `alert_type`, `alert_level` |
| 压缩排序字段 | `create_time DESC` |
| 压缩策略 | 数据超过 `90 days` 后压缩 |
| 压缩任务执行间隔 | `12 hours` |

## t_alert_threshold

告警阈值配置表。该表为普通 PostgreSQL 表。

### 字段

| 序号 | 字段 | 类型 | 可空 | 默认值 | 说明 |
| ---: | --- | --- | :---: | --- | --- |
| 1 | `id` | `character varying(32)` | 否 | - | 阈值规则主键，32位UUID |
| 2 | `sensor_no` | `character varying(50)` | 否 | - | 传感器编号，关联 `t_sensor.sensor_no` |
| 3 | `physical_quantity` | `character varying(50)` | 否 | - | 监测物理量名称，例如应变、温度、湿度、风速 |
| 4 | `create_time` | `timestamp(6) without time zone` | 是 | `CURRENT_TIMESTAMP` | 创建时间 |
| 5 | `update_time` | `timestamp(6) without time zone` | 是 | `CURRENT_TIMESTAMP` | 修改时间 |
| 6 | `channel` | `character varying(50)` | 否 | `''::character varying` | 监测通道，空字符串表示默认通道 |
| 7 | `level1_upper` | `numeric(15,5)` | 是 | - | 一级告警上限，监测值大于该值时触发一级红色告警 |
| 8 | `level1_lower` | `numeric(15,5)` | 是 | - | 一级告警下限，监测值小于该值时触发一级红色告警 |
| 9 | `level2_upper` | `numeric(15,5)` | 是 | - | 二级告警上限，监测值大于该值时触发二级橙色告警 |
| 10 | `level2_lower` | `numeric(15,5)` | 是 | - | 二级告警下限，监测值小于该值时触发二级橙色告警 |
| 11 | `level3_upper` | `numeric(15,5)` | 是 | - | 三级告警上限，监测值大于该值时触发三级黄色告警 |
| 12 | `level3_lower` | `numeric(15,5)` | 是 | - | 三级告警下限，监测值小于该值时触发三级黄色告警 |
| 13 | `update_by` | `character varying(64)` | 是 | - | 修改人 |
| 14 | `create_by` | `character varying(64)` | 是 | `''::character varying` | 创建人 |
| 15 | `range_min` | `numeric(15,5)` | 是 | - | 传感器量程最小值，按监测物理量或通道从 `t_sensor.range` 匹配 |
| 16 | `range_max` | `numeric(15,5)` | 是 | - | 传感器量程最大值，按监测物理量或通道从 `t_sensor.range` 匹配 |
| 17 | `threshold_basis` | `character varying(1000)` | 是 | - | 设置阈值等级和量程时采用的依据 |
| 18 | `alert_function` | `integer` | 是 | - | 预警功能分类：1=结构，2=环境 |
